A Jupyter notebook demonstrating Biobox main functionalities

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/Degiacomi-Lab/biobox_notebook/HEAD)

Biobox's documentation is available at https://biobox.readthedocs.io

To run the notebook on your computer, create its environment (which installs Biobox from conda-forge) and start Jupyter:

```
conda env create -f environment.yml
conda activate notebook_env
conda install -c conda-forge jupyter
jupyter notebook BiobOx_overview.ipynb
```
